Import lots from a CSV

The file needs a header row with these four columns: Symbol, Date, Shares, Cost per Share (Buy Date still works). Dates read as MM/DD/YYYY or YYYY-MM-DD; leave the cell empty for a lot with no date. Export CSV writes this exact shape, so a file from here imports straight back.

Add a Kind column of Buy or Sell to bring sales in too. On a sell row, Cost per Share is the price you sold at, the date is required, and an optional Lot cell of YYYY-MM-DD@cost says which lot it came out of — leave it empty and the oldest open lot goes first. A row with no Kind is a purchase, so files written before sales existed still read correctly.

Two more columns are optional, and the downloaded report compares both by dollar value. Category says what kind of holding the symbol is (ETF, Stock, REIT, Bond, whatever split you think in) — tag a symbol on any one of its rows and its other rows inherit it, since a category describes the symbol. Account says where the lot is held (Taxable, Roth IRA, 401k); it is read per row and never inherited, because the same symbol is often held in more than one account. Untagged rows count as Uncategorized and Unassigned.
