Revise with Q Standalone

Welcome to Revise with Q

Import a .txt file with one item per line. Everything runs in this browser tab — no server needed. Each line will be displayed as a card and read aloud. Navigate with the buttons, keyboard arrows, or swipe.

Question-and-answer files belong in Study with QA — if you import one here, this app will say so rather than splitting the answers into their own cards.
