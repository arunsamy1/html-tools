e-dumper One Liner Q v2.2

A one-at-a-time text viewer that reads each line aloud as you navigate — ideal for reviewing quotes, proverbs, interview questions, or any line-by-line content.

Quick Start

  1. Open e-dumper-oneline-q-voice.html in any modern web browser
  2. Import your text file using the "Import Text" button in the sidebar
  3. Each line is read aloud automatically as you navigate
  4. Use Previous/Next buttons, arrow keys, or swipe left/right on mobile

Features

Voice Playback

  • Each line is automatically read aloud when displayed
  • Tap the 🔊 Replay button to hear the current line again
  • Uses the browser's built-in Web Speech API — no internet required

Display

  • Shows one line at a time for focused reading
  • Large, easy-to-read text display
  • Progress indicator (X of Y lines)

Organization

  • Shuffle lines to randomize order
  • Navigate forward and backward through content

Mobile

  • Swipe left to go to the next line, swipe right to go back
  • Optimized for notched phones (safe-area insets)
  • Responsive layout for all screen sizes

Use Cases

  • Memorizing quotes and proverbs
  • Reviewing interview questions one at a time
  • Studying one fact at a time
  • Listening to content hands-free while on the move

File Format

Text files should be plain text (.txt) with one item per line:

The early bird catches the worm.
A stitch in time saves nine.
Actions speak louder than words.
Better late than never.
Birds of a feather flock together.

Format Rules

  • One line per item
  • Lines are trimmed of leading/trailing whitespace
  • Empty lines are ignored

Navigation

Input Action
Right Arrow key Next line
Left Arrow key Previous line
Swipe left Next line
Swipe right Previous line
🔊 Replay button Re-read current line
Note: On iOS, speech playback requires a user interaction first (tap/swipe). Lines loaded from saved state on page load will display silently; the first navigation will activate audio.

Data Persistence

Your progress is automatically saved to localStorage:

  • Current line position
  • Loaded lines

Click "Clear Progress" in the sidebar to reset all data.

Running the App

Simply open e-dumper-oneline-q-voice.html in a browser. No server required.

# Using Python
python -m http.server 8000

# Using npx
npx serve .

Then open http://localhost:8000/e-dumper-oneline-q-voice.html

Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge). Web Speech API is supported in Chrome, Edge, and Safari; Firefox support may vary.
