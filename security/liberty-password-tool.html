Notes
• {xor} is obfuscation, not encryption: each UTF-8 byte is XOR'd with _ (0x5F) and Base64-encoded. Anyone can reverse it.
• {aes} values (--encoding=aes) can't be decoded here — they depend on the server's AES key.
• {hash} values (--encoding=hash) are one-way and can't be decoded at all.
• Example: securityUtility encode password → {xor}Lz4sLCgwLTs=
